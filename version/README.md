## 🔖 Versioning

نسخه‌های این پوشه بر اساس **Semantic Versioning** نام‌گذاری می‌شوند:

```text
vMAJOR.MINOR.PATCH
```

### ساختار نسخه

* **MAJOR** — تغییرات بزرگ و ناسازگار با نسخه‌های قبلی
* **MINOR** — اضافه شدن قابلیت‌های جدید با حفظ سازگاری
* **PATCH** — رفع باگ‌ها، اصلاحات و بهبودهای کوچک

با انتشار هر نسخه جدید، فایل ZIP مربوط به آن نسخه به این آرشیو اضافه خواهد شد و نسخه‌های قبلی بدون تغییر باقی می‌مانند.
