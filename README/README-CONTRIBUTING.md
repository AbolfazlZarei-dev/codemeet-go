# نگهداری README

- هر موضوع اصلی در فایل مستقل باقی بماند.
- مثال‌ها Token واقعی نداشته باشند.
- تغییرات API در changelog ثبت شوند.
- Version هنگام release بررسی شود.
- Endpoint availability از SDK Method جدا نگه داشته شود.
- تغییرات breaking در فایل‌های مربوط به API/Models برجسته شوند.

## اصل ثابت

> **وجود یک Method در کتابخانه الزاماً به معنی فعال بودن Endpoint متناظر آن در Bot API نسخه‌ی فعلی نیست.**
