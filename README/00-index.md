# CodeMeet-Go v1.1.0 — Documentation

مستندات رسمی و تفکیک‌شده کتابخانه **CodeMeet-Go**. هر موضوع در یک فایل Markdown مستقل قرار گرفته است.

> **وجود یک Method در کتابخانه الزاماً به معنی فعال بودن Endpoint متناظر آن در Bot API نسخه‌ی فعلی نیست.**

این مجموعه بر اساس سورس ارائه‌شده برای نسخه `1.1.0` و مستندات موجود پروژه تنظیم شده است؛ جایی که سرویس سمت سرور را نمی‌توان از سورس SDK اثبات کرد، آن مورد صریحاً به‌عنوان نیازمند بررسی API مقصد مشخص شده است.
